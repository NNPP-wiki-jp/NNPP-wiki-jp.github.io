Full Reactor Guide

原子炉（Reactor）は、ナラモ原子力発電所（Naramo Nuclear Power Plant）の中心的な存在である。エネルギー省（Department of Energy）およびその職員にとって、原子炉を維持し電力を生産し続けることが絶え間ない目標である一方、ウエスト・ヌービアン突撃部隊（West Noobian Assault Force）とその支援を行うブロックス人の同盟者たちにとっても、いかなる犠牲を払ってでも原子炉を破壊することが変わらぬ目的であり続けている。このページでは、原子炉の機能の概要と、その操作方法についての情報を提供する。

Basics

原子炉オペレーション（RO）の主な任務は、原子炉を安全かつ効率的に管理することである。電力注文（Power Orders）の達成は、全施設従業員にとって主要なXP獲得源となるため、最も重要な任務となる。原子炉の管理はすべて制御室（Control Room）内で行われる。

原子炉の仕組み

原子炉は制御棒（このガイドでは単に「ロッド」と呼ぶ）と燃料棒で構成されている。燃料棒内で核反応が発生し、それが制御棒によって制御される。原子炉は熱を発生させ、その熱が水を蒸気に変え、蒸気がタービンを駆動して発電する。

Reactor controls

制御室はコントロールパネルのある5つのセクションに分かれている。プライマリコントロールとグリッドコントロールがメインであり、残りの3つは使用頻度が低く、少し後で詳しく学ぶことになる。

Primary controls

プライマリコントロールの主な任務は、安定した安全な原子炉温度を維持することである。ガイドの以降のセクションでは、温度設定と、特定の温度を維持するのがいつ最適であるかについて学ぶ。

  1. Feedwater controls（給水コントロール）: 両方の給水ポンプを制御するために使用される。給水システムの設計と動作については後のセクションで学ぶ。最も知っておかなければならない重要なことは、給水バルブを決してオフにしないことである。
  2. Control Rods（制御棒）: 主要な温度制御装置。下げることで連鎖反応が減速・停止し、温度が下がる。上げることで反応が加速し、温度が上がる。
    • 100%: 最大冷却（-9 K/s）
    • 55%: 十分な燃料レベル（75%以上）において温度を安定させるための最も安定したポジション。原子炉の燃料レベルが75%未満の場合、ロッドを100%まで下げて冷却水をオフにすることができる。あるいは36%以下に下げることもできるが、依然として冷却水に依存することになる。このロッド設定では燃料の消耗が早くなる。
    • 0%: 最高温度上昇（+11 K/s） [絶対に非推奨]

    もう一つの補足として、ロッドの1%は温度を0.2 K/s上下させる。

  3. Coolant Valve（冷却水バルブ）: 冷却水ポンプから原子炉へ冷却水を供給する。冷却水ポンプは常にオンにしておかなければならない。オフにされた場合は緊急事態であり、ロッドを下げる必要がある。ただし、温度を上げる必要がある場合は一時的に冷却水バルブを閉じることもできる（SCRAMテストを行いたい場合はこれが最適の選択肢となる）。
  4. Main notification panel（メイン通知パネル）: 冷却水ポンプや給水が機能していないときに表示される。この場合、DOE無線でプラントメンテナンスに通知する。原子炉温度が上昇した理由がわからない場合は、このパネルを確認すること。
  5. SKALA panel: レイド中にハッキングされたコンピュータを表示する（ほとんど役に立たない）。
  6. Relief Valves（逃し弁）: 緊急時などに温度を素早く下げるために使用される。各弁はサイクル（10秒）ごとに75K（-198.15°C / -324.67°F）の温度を下げ、90秒のクールダウンがある。逃し弁はスタックするため、順番に開く必要はな・い・。4つすべてを同時に開くと、それに応じて温度が約300K下がる。

Grid controls

  1. Grid terminal（グリッド端末）: Eキーを長押しして開く。開いたら画面を右クリックするとテキストアニメーションを素早くスキップできる。開いた後、キーボードの数字キーを使用してグリッドを切り替える。「グリッドとグリッドコントロール」のセクションで、グリッドの仕組みと使用方法を学ぶ。
  2. Turbines control panel（タービンコントロールパネル）: 両方のタービンのコントロールパネル。「タービンコントロール」のセクションでタービンコントロール自体について学ぶ。

Feedwater

給水（Feedwater）または原子炉水は、原子炉にとって最も重要かつ主要な冷却システムである。原子炉水は、その後にタービンを駆動する蒸気の生成にも使用される。このため、給水レベルはいかなる状況下でも常に100%でなければならない。給水バルブを使用して原子炉温度を上げることは強く非推奨である。

給水コントロール：

  1. Feedwater pump parameters: 現在の給水ポンプの負荷、回転速度、および生成された流量を表示する。利用率は給水ポンプの摩耗率に直接影響しないが、利用率が80%を超えるとタービンが振動し始め、摩耗の増大および給水ポンプ爆発の可能性が大幅に高まる。このパラメータを80%のわずかに手前、約79.5%に維持することが強く推奨される。通常、各ポンプの流量は0.92である。
  2. Total reactor water indicators: 総給水流量と原子炉水位を表示する。水位は常に100%でなければならない。
  3. FW pump switches: 給水ポンプの利用率を直接調整する。
  4. Feedwater valve: 原子炉への給水流量を閉じたり開いたりする。常に開いたままにしておくこと。

INFO: 温度が1,750K未満の場合、システムは1台の給水ポンプの喪失（全体の給水流量が0.92に減少）に対処できる。しかし、温度がそれより高い場合、たった1台の給水ポンプの喪失でも原子炉の水位が急激に低下し、過熱とトリップ（停止）を引き起こす。

INFO: 給水ポンプの利用率のパーセンテージは、その電力消費量に直接影響する。そのため、タービングリッド構成を使用している場合は、ポンプの利用率を下げることで消費電力を削減できる。ただし、原子炉の水位が必要なレベルに維持されるよう必ず監視すること。

Turbine controls and syncing

タービンはまさに電力が生成される場所である。同期されたタービンのみが発電し、グリッドに接続できる。タービンのRPM（回転数）が5,000に達した場合（非同期時）、または摩耗が0%に達した場合（PMや高ランクROが使用できるレンチツールを使用して確認可能）、タービンが爆発する可能性がある。同期されたタービンは、流量が1.5 m3/sを下回った場合（バルブのパーセンテージが低すぎる場合や原子炉の給水レベルが低い場合など）、同期が外れる（トリップする）ことがある。外部グリッドが失われた場合、ステーション全体に完全に電力を供給できるのはタービンだけであるため、常にできるだけ早くすべてのタービンを同期させるよう努めること。

  1. Valve opening percentage: パーセンテージが高いほど流量が増え、同期時のエネルギーが増加する。このパーセンテージはバルブスイッチ（5）によって直接制御される。
  2. Flow-rate: タービンの現在のスループット容量を表示する。
  3. Turbine RPM: タービンが同期しているとき、RPMは3,000 RPMに固定される。
  4. Synchroscope: 同期ボタン（7）を押す適切なタイミングを判断するために必要。
  5. Valve switch: バルブの開き具合のパーセンテージを直接調整する。超過分を制御し、パワーオーダーを遂行するための主要な方法。
  6. Turbine accelerator: タービンが非同期のときのみ使用され、RPMが増加または減少する速度を変更する（同期されるとRPMは3,000に固定される）。Fは高速、Mは中速、Sは低速。タービンが同期された後、アクセル位置を変更しても、振動を含めて一切の効果はない。
  7. Turbine synchronization button: RPMが2,990から3,010の間にあるときにこのボタンを使用してタービンの同期を試みることができる。回転する赤い円がシンスコープの真上、2つのゼニス円のエリアにあるときにボタンを押す。

タービンの振動：

タービンの振動レベルは、その摩耗率、ひいては爆発の確率に直接影響する。振動を軽減するには：

  • # 1. タービンが非同期のときにアクセルを「S」（低速）モードに切り替える。
  • # 2. パワーオーダーを実行するときを含め、二重の「++」や「--」ではなく、単一の「+」や「-」をバルブスイッチで使用する。
  • # 3. 両方のタービンのバルブ%をほぼ同じレベルに維持するように努める。

タービンは、給水ポンプと同様に、サーバー上にプラントメンテナンス（PM）がいない場合は摩耗しない。

サーバー上に十分なPMがおり、彼らが絶えずタービンを修理している場合は、通常、振動を無視して「++」や「--」の記号を使用してもよいが、注意深く監視し、アラーム音やタービン端末の警告で示される危険なレベルに達しないようにすること。

タービン同期手順：

  • # 原子炉温度が安定していることを確認する（厳密に1,420Kである必要はない）。ロッド55%、すべての冷却水ポンプとバルブ=ON、給水バルブ=ON、給水レベル=100%、原子炉燃料レベル76%超。原子炉温度が安定していない場合、必要な流量を維持することは非常に難しいが、それでもタービンの同期を試みることはできる。
  • # バルブスイッチ（5）を使用して、RPMが2,700未満の場合は流量を約3.80%にし、RPMが3,300超の場合は約3.40%にする。
  • # RPMが2,950から3,050の範囲にあるとき、流量を正確に3,61%にして維持する。
  • # RPMが2,990または3,010に達するまで待ち、タービンアクセルが「S」（低速）モードになっていることを確認する。
  • # ここで、赤い点が円の最上部（緑色のゾーン）にある瞬間を待ち、タービン同期ボタン（7）を押す。

INFO: タービンを同期できる絶対的な最低温度は約530Kである。

Grids and energy

すべての原子炉冷却システム（冷却水、給水）には電力が必要であり、電力が供給されていない場合は機能しない。

External grid（外部グリッド）: 他のすべてのステーションや都市、工場などの消費者を接続する国家ネットワークであり、ステーションのタービンからの超過電力が流れ込む。そのため、ステーションにとって電力の消費者にも供給者にもなり得る。外部グリッドを使用して施設に電力を供給している場合、実際にはその両方を同時に行っている。

Excess power（超過電力）: パワーオーダーをこなすために国家グリッドに送られるエネルギー量。

この図は、電力がどのように分配され、どこから来るのかを正確に示している：
緑 - 供給者、赤 - 消費者

INFO: グリッドコントロールセクションでは、タービンが現在どれだけのエネルギーを生成しているか（タービン出力）を確認できる。すべての冷却水に電力を供給するためにタービングリッドを使用する場合、ステーション全体に電力を供給するには少なくとも23,320 kWのタービン出力が必要となる。

グリッドは複雑に見えるが、通常の運用中に使用されるのは2つの構成と、主要なものが利用できない場合の緊急時の1つの構成のみである。

グリッド構成

External configuration（外部構成）:

  • (1 および 4) ステーション全体が外部グリッドのみによって電力を供給されているため、タービンからのすべてのエネルギーが直接パワーオーダーの達成に使われる（これはまさに、外部グリッドが消費者と供給者の両方であるケースである）。
  • 考えられるリスク:
    • ウエスト・ヌービアンによる変圧器の破壊
  • 利点:
    • パワーオーダー実行のための温度をはるかに低く保つことができ、あるいは同じ温度でより多くの超過分を得ることができる。タービンで生成されたエネルギーがステーションの電力供給に使われず、ステーションは外部グリッドから完全に電力を供給されるため。

Turbine configuration（タービン構成）:

  • (1 および 3) ステーション全体がタービンによって電力が供給され、超過電力が国家グリッドに送られパワーオーダーに使用される。このグリッドを使用するには少なくとも1つの同期されたタービンが必要だが、できるだけ早く両方を同期させるように努めること。1つのタービンだけでステーションに電力を供給するには、少なくとも1,420Kの温度を取得し、タービンバルブを100%に設定する必要がある。このグリッドへの切り替え時にブラックアウトが発生した場合は、単にタービンバルブのパーセンテージを上げ、原子炉温度が1,400Kを下回っていないことを確認すること。
  • 考えられるリスク:
    • ランダムなタービンの爆発
    • 給水ポンプの喪失
  • 利点:
    • ステーションが変圧器から完全に独立する。

これら2つのグリッドのどちらがより安全かについての普遍的な答えはない。すべてはサーバー上の状況次第である。ただし、サーバー上にWNが全くいない場合は、WNだけが変圧器を破壊できるため、外部グリッドの方が安全である。

Emergency configuration（緊急構成）:

  • (2) 原子炉グリッドが利用できない場合（変圧器が破壊され、かつ両方のタービンが非同期の場合）のみ使用される。補助グリッドは発電機によって電力供給され、原子炉グリッドは電力が供給されないままであるため、原子炉冷却の半分しか機能しない。

INFO: DCバスを切断しても意味がない。発電機はすでに補助バスが消費できる以上の電気を生成している。冷却システムには最初に電力が供給される。電力不足（3台中1台の発電機しか稼働していないなど）がある場合でも、利用可能なすべてのエネルギーは最初に冷却システムに送られる。

INFO: 給水ポンプの利用率のパーセンテージは電力消費に直接影響する。そのため、タービングリッド構成を使用している場合は、ポンプ利用率を下げることで消費電力を減らすことができる。ただし、原子炉の水位が100%のレベルに維持されるよう必ず監視すること。

外部構成を使用する場合：超過電力 ＝ タービン総電力

タービン構成を使用する場合：超過電力 ＝ タービン総電力 － 30,000kW（ステーション自体の消費）。（23,320kWはすべての冷却水に電力を供給するため「だけ」のものであり、ポの実行を開始するには、超過電力を生成するために30,000kWを超えなければならない。）

Policies

ゲーム内のポリシーは、プラントディレクターが招集する会議で提案され、その後役員やその他の高ランクが投票する。ゲーム内には多くのポリシーがあるが、原子炉運営に直接影響するのは次の2つのみである：

Power order efficiency act（電力注文効率法）:

  • パワーオーダーが倍増し、達成時の報酬も倍増する（150xpの代わりに300xp）。このポリシーがサーバーで承認されたからといって、自動的に温度を上げなければならないわけではなく、外部グリッドを使用している場合は1,420Kの温度でも二重パワーオーダーをこなすことができる。

Hazard pay bill（危険手当法）:

  • 温度が2,100Kより高い場合、温度の高さに応じて少額のXPボーナスを受け取ることができる。しかし、温度が2,100Kより低い場合、ボーナスはマイナスになり、獲得できるXPが減少する。これはかなり疑問の残るポリシーである。しかし、必ずしもこれに従う必要はない点に留意すること。

サーバーでどのポリシーが有効かは、制御室の奥の壁にあるパネルで確認できる：

Power orders

パワーオーダーはすべての従業員がXPを稼ぐ主な方法であるため、安全性の次に最優先すべき事項である。電力注文効率ポリシー（二重パワーオーダー）がない場合、POは15,000から24,500の範囲、またはポリシーが承認されている場合は30,000から49,000の範囲でランダムに出現する。二重パワーオーダーを実行するには、通常、49,000までの全範囲をカバーするには1つでは不十分なため、両方の同期されたタービンが必要となる。

通常時の原子炉運営における3つの主な「モード」：

# 維持する温度 使用するグリッド構成 長所と短所
1 1,420K 外部 (External) 🟢 温度を上げずに二重パワーオーダーを実行できる
🔴 外部グリッドに依存する
2 1,420K タービン (Turbines) 🟢 外部グリッドに依存しない
🔴 標準サイズのパワーオーダーのみ実行可能
3 2,100K以上 タービン (外部も使用可) 🟢 二重と通常のパワーオーダーの両方を実行でき、同時に危険手当も得られる（このポリシーが有効な場合）
🔴 はるかに危険であり、給水ポンプの喪失（メルトダウンを引き起こす可能性さえある）に非常に敏感

パワーオーダー手順：

  • # すべての冷却システムが正常に動作し、原子炉温度が安定していることを確認する。
  • # 両方のタービンを同期させる。
  • # SMおよびPDと共に、維持する原子炉温度を選択する。上記のモード表を使用すること。
  • # Shift Manager（SM）またはDirector（PD）がシフトマネージャーパネルでパワーオーダーを有効にしていることを確認する。
  • # POを受信すると、大きなメインパネルの「power order」という文字の横に必要な超過分（2）と許容される「誤差範囲（margin for error）」（3）が表示される。これは、PO = 21,108で誤差範囲 = 1,161の場合、指定された時間（4）の間、超過分（1）を19,947から22,269の範囲（簡単な計算）内に維持する必要があり、そうすればPOが実行されることを意味する。スイッチ（+または-）を使用してタービンバルブ%を変更することで、超過分を調整できる。

INFO: シフトの終了時に、ティアに応じたサイズの一時金ボーナスを受け取る：

  • Tier 1: 0 ～ 3 POs → 500 XP
  • Tier 2: 4 ～ 6 POs → 1,000 XP
  • Tier 3: 7回以上のPOs → 3,000 XP

INFO: 原子炉運営に精通している人なら察しているかもしれないが、パワーオーダーはタービンだけでなく、ロッド / CV / RVを介して直接原子炉温度を変更することでも実行できる。温度上昇は、両方の同期されたタービンが100%バルブで、かつPOを完了するのに超過分が不足している場合に「のみ」適用すること。

INFO: PO（パワーオーダー）がないときは、超過分を約19,000に維持しておくこと。そうすれば、POを受信したときに、PO受信後に必要な超過分に素早く到達できる（x2パワーオーダーを使用している場合は39,500）。

Emergency protocol

1! 制御室へのWN侵入

  • # DOE無線で「WN CR」などと発言して直ちに警備を呼ぶ。
  • # ロッドを100%まで上げる（※原文ママ、文脈的に下げることだが原文記述に従う）。
  • # すべての逃し弁を使用する。
  • # WNがタービンをトリップさせようとするため、グリッドを外部構成に切り替える。
  • # 隠れて、いかなる手段を使ってでも彼らがメルトダウンを引き起こすのを防ぐよう努める。

常に状況を監視し、制御室の近くにWNがいて警備が不十分な場合は、直ちにロッドを100%にし、すべての逃し弁を使用すること。制御室へのWN侵入時の原子炉の温度が低いほど、あなたと警備が原子炉を救う可能性が高まる。

WNは制御室内のロッド、冷却水、給水、タービンなど、ほぼすべてのボタンを押すことができる点に注意すること。したがって、彼らが制御室に入り込むと、それは危機的であり、実際上最も危険な状況となる。WNはシフトマネージャーのコントロールを使用したり、原子炉を点火したりすることはできない。

2! 冷却水ポンプの停止

  • # ロッドを100%まで下げる（冷却水ポンプが1台のみダウンしている場合は80%）。
  • # DOE無線でPMを呼ぶか、自分で冷却水をONにしに行く。
  • # 温度が1,450K+に達した場合は逃し弁のサイクルを開始し、1,600Kを超える場合はすべて使用する。

3! 原子炉の水位が低下している

INFO: ~1,750K未満の温度では、両方の給水ポンプが故障した場合にのみ原子炉の水位が低下するが、より高い温度では、たった1台のポンプの故障でも原子炉の水位が急激に低下する。

  • # DOE無線でPMを呼ぶ。
  • # ロッドを100%まで下げる。
  • # タービンが可能な限り長く動作し続けるようにタービンバルブを100%に設定するが、トリップ（非同期）することに備えておく。
  • # 温度が1,450K+に達した場合は逃し弁のサイクルを開始し、1,600Kを超える場合はすべて使用する。
  • # 水位の低下が続く場合は、外部グリッド構成に切り替える準備をしておく。外部グリッドが利用できない場合は、緊急事態5に備える。
  • # 原子炉の水位が低すぎ、温度が高すぎる場合、80%の双方向ポンプは蒸発するよりも速く水を補充できず、暴走反応につながる。原子炉を復旧させるには、事前にPMに警告し、給水コントロールを使用して流量を増やし、水位を回復させること（外部グリッド推奨）。

4! 外部グリッドの電力喪失 AND タービンの1つが非同期

  • # グリッドをタービンに切り替える（タービン構成）。
  • # 同期されたタービンを100%バルブにする。
  • # 原子炉温度が1,400Kを下回っていないことを確認する。
  • # 変圧器に警備とPMを呼び、外部グリッドをできるだけ早く修理してもらう。
  • # 2つ目のタービンをできるだけ早く同期させるよう努める。

5! 外部グリッドの電力喪失 AND 両方のタービンが非同期

  • # グリッドを発電機に切り替える（緊急構成）。
  • # 少なくとも2台の発電機が稼働していることを確認する。
  • # DCバスから電力を遮断する（必須ではないが推奨、シフトマネージャーに頼んで行ってもらう）。
  • # 変圧器に警備とPMを呼び、外部グリッドをできるだけ早く修理してもらう。
  • # 温度が安定している場合は、できるだけ早くタービンの同期を試みる。
  • # 温度が上昇している場合は、ロッドを下げて逃し弁を使用し、安定化を試みる。可能であれば、原子炉を一時停止（ストール）させる方が安全である。

原子炉を安定させるには、温度を1,750K以下に下げて1台の給水ポンプを効率的に使用できるようにし（発電機稼働時に冷却水が1台ダウンしているため）、温度が1,750K未満の場合はロッドを80%に上げ、そうでない場合は時間を稼ぎ/1,750K未満に下げるためにロッドを100%にする。温度を1,750K未満に下げられない場合は、1つまたは2つのRVを使用するか、外部が制圧されたりPMが向かっていない/いない場合はすべてを解放して、PMと警備に変圧器を確保する時間を与えること。

RVを使用すると流量が一時的に増加し、原子炉により多くの水を供給すると同時に温度が下がるため、これを温度を下げながら水位を上げるために使用できることに留意すること。低温は水面蒸発を遅らせる。

6! WNレイド開始

  • # 原子炉のストールに備える（次のセクションで原子炉ストール手順について学ぶ）。

WARNING: レイドの第2ステージ中、WNはステーション内のコンピュータ（SCALA）を攻撃する。それぞれが自身の機能を担当しており、ハッキングされると機能が動作しなくなる（例えば、ロッドを下げたり逃し弁を使用したりできなくなる）ため、レイドの第2ステージが始まる前（街が陥落したとき）に原子炉をストールさせなければならない。ただし、サーバーに多くのWNがいる場合は、警備が街に気を取られている隙をついてステーションや制御室を襲撃される可能性があるため、レイド開始直後に原子炉をストールさせることもできる。

WARNING: 原子炉温度が約3,500Kを超える場合、爆発から救うのはほぼ不可能である。無線で避難の開始をアナウンスすること。4,000を超えると、生存のチャンスは完全にゼロになる。

WARNING: 外部グリッドの電力が失われた場合は、両方のタービンが同期していてもそれを失うことは本当に危険であるため、PMができるだけ早く修理するように確実に行うこと。

Reactor stall procedure

原子炉ストール（Reactor stall）とは、最低原子炉温度（323K）に到達し、通常の原子炉運営が完全に安全になるまでその温度を維持する手順である。温度が323Kのとき、原子炉は冷却システムが完全に失われていても冷却を維持できるため、運営が脅かされているときに原子炉の安全性を確保するために必要となる。

いつ原子炉ストールが必要か？

  • # 制御室へのWN侵入、または制御室に非常に近い場合
  • # レイド（状況に応じて、レイド開始直後にストールを開始するか、WNが200-250ポイントを獲得しGSPが勝利に近くない場合にストールする）
  • # 冷却水の度重なる停止、外部グリッドの喪失、および安定した原子炉制御を妨げるその他の問題。

WARNING: 原子炉ストールはSCRAMテストのようなXPを与えないため、原子炉の運営が脅かされているときのみストールを使用すること。

手順：

  • # グリッドを外部構成、または「外部」が利用できない場合は緊急構成に切り替える。温度が十分に低くなるとタービンはトリップする。
  • # ロッドを100%に下げて下げたままにする。
  • # 冷却水バルブと給水バルブがOPENであることを確認する。
  • # 逃し弁を使用してより素早くストールを実行する。
  • # 原子炉温度が323Kに達したら、すべての冷却システムをOPENにし、ロッドを100%にしたままにする。

INFO: 323Kは原子炉の可能な限り低い温度である。これより冷たくする方法はないため、温度が323Kのときに逃し弁を開く意味はない。

INFO: レイド中、原子炉ストールが完了したら、原子炉運用担当の従業員はプラント警備に切り替えてもよい。実際、原子炉をストール状態に保つために必要なのはシフトマネージャーだけでよい。

Reactor meltdown & SCRAM

温度が3,120Kに達すると、原子炉は溶融（メルトダウン）し始める。あなたの任務は、この温度に達するのをできる限り防ぐことである（PDがSCRAMテストを行いたい場合を除く）。SCRAMボタンは緊急冷却システムであり、利用可能になり次第（温度が3,120Kに達してから約45秒後）常に押すこと。3,120Kに達した後、原子炉を900K以下に冷却するまでに4分間の猶予がある。このレベルまで温度を下げないと爆発する。すべての冷却システム（SCRAMボタン、逃し弁、冷却水を含む）を100%で使用した場合にのみ、原子炉を爆発から無事に救うことができる。

SCRAMテストとは、原子炉を約3,120Kまで加熱し、利用可能なすべての冷却システムを使用して即座に冷却する手順である。SCRAMテストと実際のメルトダウンの唯一の違いは、温度上昇を制御している点である。原子炉が爆発するのを防ぐことができれば、1,000 XPを獲得できる。SCRAMテストは通常、RPプロセスや、退屈なPO実行を盛り上げるために行われる。XPを稼ぐという観点からは、SCRAMを行うよりも、通常のパワーオーダーを完了してTier 3を取得する方が有益である。

SCRAMボタン（13）は緊急コントロールパネルにある。

SCRAMテスト手順：

  • # シフトマネージャー（SM）およびディレクター（PD）からSCRAMテストの許可を得る。
  • # すべての原子炉運用者にSCRAMテストの開始を通知する。PDかSMがこれを行ってくれるとなお良い。
  • # 以下を確認する：
    • 冷却水ポンプ ON
    • 給水ポンプ ON および原子炉水位 ＝ 100%
    • 外部グリッド 利用可能
    • 発電機 稼働中（緊急時にすばやくグリッドを切り替えられるよう少なくとも1台）
    • すべての逃し弁 利用可能（有効化されておらず、クールダウン中でない）
  • # ロッドを0%にする。
  • # 冷却水バルブをOFFにする。
  • # 温度が約2,200Kにヒットしたら、ロッドを「下げる（lower）」に最大20%まで置き、その後「アイドル」（中央位置）に戻す。
  • # 温度が2,700Kにヒットしたら、ロッドを「下げる」に最大95%まで置き、その後「アイドル」（中央位置）に戻す。
  • # 温度が約3,110Kにヒットしたら、ロッドを100%まで下げ始める。
  • # 温度が正確に3,120K（~+5Kだが、それ未満ではない）にヒットしたら、冷却水バルブをONにし、ロッドが100%になっていることを確認し、すべての逃し弁を使用する（温度が約2,800Kまで下がった後、再び上昇し始めるが、これは正常である。できるだけ早くステップ10を実行すること。すべての冷却システムがアクティブであれば、温度は下がり始める）。
  • # 約45秒後、SCRAMボタンが利用可能になる。できるだけ早く押す。
  • # 利用可能なときはすべての逃し弁を引き続き使用し、温度が900Kを下回るまで行う。
  • # 温度が900K未満の場合、SCRAMテストは成功であり、完全な原子炉シャットダウンを待つ。時間内に原子炉を冷却しないと爆発する。
  • # 原子炉の再起動を待ち（1～2分かかることがある）、原子炉を点火する（原子炉点火手順）。

! 誰かが1つ以上の逃し弁を有効化し、かつ温度が約3,050Kに達しなかった場合：

  • # ロッドを55%、冷却水バルブをONにする。
  • # すべてのRVが利用可能になるまで待ち、それから初めてSCRAMテストを続行する。

! 冷却水ポンプがオフ、かつ/または原子炉の水位が低下している場合：

  • # SCRAMをキャンセルする。
  • # ロッドを100%（下げる）にし、冷却水バルブをONにする。
  • # 温度が1,600Kを超える場合はすべての逃し弁を有効化する。
  • # 両方の冷却水ポンプと給水ポンプがONになり安全になった場合に「のみ」SCRAMテストを続行する。

WARNING: SCRAM手順は干渉に非常に敏感である。冷却水のわずかな停止でも原子炉の爆発につながる可能性があるため、サーバーに多くのWNや頻繁な障害がある場合はこの手順を実行しないことが強く推奨される。

WARNING: SCRAM手順の実行中、ロッドのジャムが発生する可能性がある。手順を厳密に守っていれば、その確率はほぼゼロである。これが発生した場合、ロッドパネルには%の数字の代わりに「ERROR」と表示される。この場合、原子炉を救うことは不可能である。爆発は避けられない。

WARNING: 温度が約3,300Kを超える、および/または冷却システムが100%の容量で稼働していない場合、SCRAMを成功させられない確率が99%ある。温度が3,120Kに達した後、常に「直ちに」原子炉の最大冷却を開始すること。

WARNING: 画面の隅に対応する通知が表示されている公式のWNレイド中、原子炉はメルトダウンを起こさないが、レイドが終了するとすぐに、温度を正常に戻していない場合は原子炉のメルトダウンが直ちに始まる。

INFO: 外部グリッドまたはタービングリッドのいずれかを使用して、SCRAMテストを正常に実行できる。これらのグリッド構成のそれぞれの長所と短所を考慮すること。SCRAMテスト中にタービングリッドを使用することに決めた場合、原子炉温度が約1,000Kを下回ったときに、ブラックアウトを避けるために外部に切り替えることが推奨される。

Other tips and information

TIP: 実際、原子炉を効率的に管理するために必要なのは、経験豊富なプレイヤー2〜3人とシフトマネージャーだけである。制御室に人が多ければ多いほど、すべてが混沌とし、原子炉の操作が難しくなる。特にコントロールの近くでは、群がらないようにすること。

TIP: メインコントロール（ロッド/CV/RVs）で作業している場合は、温度をできるだけ安定させるように努めること。温度が変化すると、温度が原子炉の蒸気生産に直接影響するためタービンの制御が非常に難しくなるためである。定常値のわずかに上/下の安定した温度を維持する方が、常に調整を続けてタービン制御の困難につながるよりも優れている。温度を変更する前に、アクティブなパワーオーダーがないことを確認すること（例外：緊急事態）。

TIP: タービンのRPMが3,000を超えて非常に速く上昇する場合は、過回転によるタービン爆発を防ぐためにアクセルを「S」モードに切り替え、バルブコントロールを--に設定すること。

TIP: 現在パワーオーダーが実行されている場合は、グリッドを切り替えないこと。まずパワーオーダーを完了してから、グリッドを切り替えること（緊急シナリオを除く）。

TIP: 1,420Kの安定した温度では、流量3.61は約42.7%のタービンバルブで達成される。

TIP: DCバスが換気に電力を供給しているにもかかわらず、SMが補助からDCバスへの電力を遮断した場合でも、WNや民間人は引き続き通気口を使用できる。DC電源バスを切断しても、換気ファンブレードは停止しないことに注意すること。したがって、施設を暗くしたいのでない限り、DCバスを切断しても意味がない。
