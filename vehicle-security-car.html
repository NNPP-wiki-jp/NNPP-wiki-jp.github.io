Security Car

Basic security patrol vehicle, issued to facility security personnel.

Security Carは、プラント警備および戦術対応チーム（TRT）向けの標準的な移動用車両であり、両チームのスターター車両として機能する。

最大4名まで乗車可能であり、最高速度75に到達する性能を持つため、メイン施設への人員輸送や新規プレイヤーの移動手段として信頼できる選択肢となっている。

外見

Security Carは、四角ばった形状の白いワゴン・エステート車である。ストリートワゴンに似ており、フラットなルーフライン、側面の大きな窓、そして荷台エリアを備えた長いステーションワゴンのようなボディを持つ。

ストリートワゴンとの最大の相違点は、ルーフ上に搭載された2つのパトライトであり、作動させると黄色い光を点滅させる。車体には、側面に2本の青い水平ストライプが走り、ドアには青字で「SECURITY」および「DIAL 199」、さらに車体後方にも「DIAL 199」の文字がプリントされている。また、前後バンパーの両方には黄色いフォグランプが備わっている。

Tips

  • Security Carはクールダウンがなく4座席を備えているため、原子力メルトダウン時の脱出やプラント内での人員輸送に非常に優れた選択肢となる。

長所と短所

長所

  • クールダウンなし
  • まともな速度
  • 概ね非常に安定している

短所

  • 装甲がないため、歩兵や搭載武器に対して非常に脆弱。
    • 旋回中にわずかな傾斜を乗り越えると、簡単に横転してしまう。
    あまりかっこよくない。

トリビア

PUBLISH 3400アップデートにおいて、Security Carには連邦レンジャー連隊が施設へ密かに侵入するために使用するバリアントが追加された。

そしてEXECUTIVE AUTHORITYアップデートの後、Security Carにはさらに「セキュリティ・スーパーバイザー・カー」と「強化警備車両」という2つのバリアントが追加された。
